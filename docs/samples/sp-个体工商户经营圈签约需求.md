# 个体工商户手机签约与经营圈需求说明（样例）

## 一、政策与战略背景（为什么做这个产品）

1. **中央金融工作会议（2023 年 10 月）** 提出做好「科技金融、绿色金融、**普惠金融**、养老金融、数字金融」五篇大文章，
   普惠金融的重点服务对象是**小微企业、个体工商户**与民营经济。
2. **国务院《关于推进普惠金融高质量发展的实施意见》**：提高小微与个体经营者融资可得性、降低综合融资成本、
   健全「**敢贷、愿贷、能贷、会贷**」长效机制，减少对抵押担保的过度依赖。
3. **金融监管总局普惠信贷年度工作要求**（近年提法概括为「保量、稳价、优结构」）：普惠型小微贷款增速不低于各项贷款增速、
   有贷款余额户数不低于年初（「两增」口径），并对**首贷户**扩面、**无还本续贷**、期限与现金流匹配提出要求。
4. **中国人民银行** 通过支农支小再贷款等结构性工具引导资金投向，配合 LPR 改革降低实际融资成本。
5. **供应链金融与「银税互动」**：以真实交易背景（合同、发票、订单）与纳税数据增信，把「主体信用」扩展为
   「**交易信用**」，引导资金沿真实经营链条流转——这正是本需求用「经营圈」承载上下游账户关系的动因。
6. **反洗钱与穿透式监管**：《反洗钱法》（2024 年修订）与受益所有人信息管理要求，叠加贷后「**经营流与资金流匹配**」，
   要求涉企与经营性资金往来**可核对、可穿透、可追责**（防挪用、防套取、防洗钱）。

## 一、需求正文

### R1 经营用户签约（个人客户新增经营签约身份）

已完成实名认证的个人客户，可以在手机银行**新增一个个体工商户经营签约用户**（同一 App、同一登录身份下切换）。
身份验证仍以**三要素**为准：姓名、证件种类、证件号码须与其已实名的个人身份一致，签约不引入其他身份主体。
签约时补充经营信息：经营名称（如有登记名称）、经营范围与所属行业、经营场所、经营起始时间、经营收款账户。
一个个人客户可签约**多个**经营用户；每个经营用户须明确**唯一的经营者**（即该自然人本人），不得由他人代持。

### R2 经营信息提交、信用评级与额度签约

经营用户签约时须提交**近三个月经营流水**（本行账户流水、他行流水导入或收款渠道流水，需可核对交易对手与摘要），
并授权查询**经营者本人征信信息**（纳税数据为可选授权）。系统依据流水规模、交易对手稳定性、征信记录与行业情况
给出**信用评级**，据此形成建议额度、利率与期限；经复核后确定该经营用户的**可贷额度**与单笔用款上限，
并在签约协议中载明。评级或额度发生变化时须通知客户并留痕。

### R3 建立经营圈（上下游账户关系）

为经营用户建立**经营圈**：以经营用户及其核心交易对手为中心，纳入上下游**账户**——可以是本行账户，
也可以涉及**对公账户**。每个圈内账户须记录：角色（上游供应商 / 下游客户 / 核心交易对手）、
关系确认依据（交易事实、合同、发票）、生效时间、失效时间与关系状态。
关系的加入、变更、退出均须由经营者确认并留痕；经营圈建立完成后，圈内账户关系的有效期内的变更以最新记录为准。

### R4 额度内授权（签约约定）

本产品**无抵押**，以信用方式或由政府性融资担保、风险补偿基金增信。签约时约定**授权范围**：
授权账户集合（仅限经营圈内账户）、单笔上限、月度上限与授权有效期；授权在核准额度内生效，
无需为每笔业务单独提交申请。圈外账户不在授权范围内。

### R5 还款与宽限期约定

签约时选择还款方式（按日计息、随借随还、无还本续贷等）并约定**还款宽限期**：
宽限期内归还本息的**免收利息**（宽限期天数与免息口径由产品参数定义，并在签约协议中明示）；
超出宽限期按合同约定计息，并触发约定的风险处置动作。

### R6 账户隔离、取现限额与分行审核（签约约定）

经营圈资金使用账户与客户的**个人账户相互隔离**：独立账号、独立用途，资金不得混用。
**取现到个人账户每月设有限额**，限额内的取现按约定办理；**超过限额须由签约分行后台审核通过后生效**。
限额调整、审核结论与操作痕迹均须留存，可供核对与追溯。


## 二、签约要素清单

**2.1 签约主体**：经营者姓名、证件种类、证件号码（三要素）；手机号码、登录凭据、设备指纹（复用个人手机银行）。

**2.2 经营信息**：经营名称（如有登记名称）、经营范围与所属行业、经营场所、经营起始时间、经营收款账户。

**2.3 经营与信用信息**：近三个月经营流水（含交易对手、金额、日期、摘要）；经营者本人征信报告；
纳税数据（可选授权）；评级结论与评级时间；可贷额度与单笔上限。

**2.4 经营圈关系**：经营圈标识、圈内账户、账户角色（上游供应商 / 下游客户 / 核心交易对手）、
关系确认依据（交易事实 / 合同 / 发票）、生效时间、失效时间、关系状态、变更记录。

**2.5 额度与授权**：额度、已用额度、授权账户集合、单笔上限、月度上限、授权有效期、
授权确认记录（经营者确认方式与时间）。

**2.6 还款与宽限**：放款金额、计息起止、还款方式、还款计划、宽限期天数、免息金额、逾期与风险处置动作。

**2.7 取现与审核**：每月取现限额、当月已取现金额、超限额审核申请、审核机构（签约分行）、审核人、
审核时间与结论。

## 三、业务规则

| 编号 | 规则 | 级别 |
|---|---|---|
| `BR1` | 经营用户必须绑定**唯一的经营者**（已完成三要素实名的本人），不得由他人代持 | 严格执行 |
| `BR2` | 近三个月经营流水为额度评估的必要材料；征信查询必须取得经营者授权 | 严格执行 |
| `BR3` | 可贷额度由评级结果与增信方式确定；单笔用款不得超过剩余可贷额度 | 严格执行 |
| `BR4` | 授权范围仅限经营圈内账户，圈外账户不在授权范围内 | 严格执行 |
| `BR5` | 本产品无抵押，采用信用方式或政府性融资担保、风险补偿基金增信 | 严格执行 |
| `BR6` | 宽限期内归还本息的免收利息；超宽限期按合同计息并触发风险处置 | 严格执行 |
| `BR7` | 经营圈资金使用账户与个人账户隔离，资金不得混用 | 严格执行 |
| `BR8` | 取现到个人账户每月限额；超限额须经签约分行后台审核通过后生效 | 严格执行 |
| `BR9` | 授权范围（账户集合、上限、有效期）变更须经营者确认并留痕，授权不得转让 | 严格执行 |
| `BR10` | 经营圈关系与授权变更须可追溯，供资金往来核对与穿透核查 | 严格执行 |
