## 一、业务背景与目标

为提升对公客户的开户效率，降低柜面平均办理时长（目标：45 分钟内完成，当前为 78 分钟），
并满足《账户管理办法》与人民银行账户实名制要求，我行对现有对公开户流程进行重构。

## 二、流程总览

**对公开户业务流程**由以下活动组成：

1. **客户预受理活动**：由客户经理完成客户意向登记与资料前置收集。
2. **资料审核活动**：由开户柜员对客户提交资料进行合规性审核。
3. **账户开立活动**：由开户柜员在核心系统中完成账户开立与凭证打印。
4. **账户激活活动**：由客户经理协助客户完成网银与结算凭证的激活。

## 三、活动明细

### 活动一：客户预受理活动
- **任务：客户意向登记**（由客户经理执行）
  - 步骤：核对客户身份证明（操作业务实体：客户）
  - 步骤：录入客户基本信息（操作业务实体：客户）
- **任务：资料清单核对**（由客户经理执行）
  - 步骤：比对企业营业执照与授权书（操作业务实体：客户、开户申请单）
  - 步骤：登记预受理结果（操作业务实体：开户申请单）

### 活动二：资料审核活动
- **任务：资料完整性审核**（由开户柜员执行）
  - 步骤：校验开户申请单要素（操作业务实体：开户申请单）
  - 步骤：查询客户存量账户（操作业务实体：账户）
- **任务：合规性审查**（由合规审查岗执行）
  - 步骤：核验反洗钱风险名单（操作业务实体：客户）
  - 步骤：出具审查意见（操作业务实体：开户申请单）

### 活动三：账户开立活动
- **任务：核心系统开户**（由开户柜员执行）
  - 步骤：创建对公账户（操作业务实体：账户）
  - 步骤：绑定结算产品（操作业务实体：账户）
  - 步骤：打印开户凭证（操作业务实体：账户）

### 活动四：账户激活活动
- **任务：电子渠道签约**（由客户经理执行）
  - 步骤：开通企业网银（操作业务实体：账户）
  - 步骤：发放客户证书（操作业务实体：客户）

## 四、系统支撑

- 各步骤分别在 **客户关系管理平台（CRM）** 与 **核心业务系统** 中完成操作；
  资料审核环节的名单核验在 **反洗钱监测系统** 中完成。
- 开户凭证的打印依赖 **凭证打印终端**（硬件资产）。

## 五、业务规则

- **规则一（严格执行）**：开户必须由客户本人或授权代理人办理，不得代办。
- **规则二（严格执行）**：资料审核未通过不得进入账户开立环节。
- **规则三（建议）**：同一客户在同一网点重复开户时，应提示柜员合并办理。

## 六、考核指标

- 对公开户平均办理时长 ≤ 45 分钟；
- 资料一次通过率 ≥ 90%。
