**两条基本约定（范围界定，放在验证文档以便需求文档保持纯业务）**

1. 主体是**个体工商户**：经营者就是已实名的自然人本人，签约不引入企业类主体（`sp-` 需求正文即按此口径书写）。
2. 需求只描述**签约过程与经营圈关系建立过程**，不涉及转账 / 支付的具体实现方式（实现细节在详细设计阶段展开）。

## 一、政策与战略背景（为什么做这个产品）

1. **中央金融工作会议（2023 年 10 月）** 提出做好「科技金融、绿色金融、**普惠金融**、养老金融、数字金融」五篇大文章，
   普惠金融的重点服务对象是**小微企业、个体工商户**与民营经济。
2. **国务院《关于推进普惠金融高质量发展的实施意见》**：提高小微与个体经营者融资可得性、降低综合融资成本、
   健全「**敢贷、愿贷、能贷、会贷**」长效机制，减少对抵押担保的过度依赖。
3. **金融监管总局普惠信贷年度工作要求**（近年提法概括为「保量、稳价、优结构」）：普惠型小微贷款增速不低于各项贷款增速、
   有贷款余额户数不低于年初（「两增」口径），并对**首贷户**扩面、**无还本续贷**、期限与现金流匹配提出要求。
4. **中国人民银行** 通过支农支小再贷款等结构性工具引导资金投向，配合 LPR 改革降低实际融资成本。
5. **供应链金融与「银税互动」**：以真实交易背景（合同、发票、订单）与纳税数据增信，把「主体信用」扩展为
   「**交易信用**」，引导资金沿真实经营链条流转——这正是本需求用「经营圈」承载上下游账户关系的动因。
6. **反洗钱与穿透式监管**：《反洗钱法》（2024 年修订）与受益所有人信息管理要求，叠加贷后「**经营流与资金流匹配**」，
   要求涉企与经营性资金往来**可核对、可穿透、可追责**（防挪用、防套取、防洗钱）。

> 以上为公开政策口径的概述性引用；落地前须核对最新官方原文。本案例只用于验证流程。

## 二、我行现行方案与计划（本需求要落地 / 复用的）

| 举措 | 与本需求的关系 |
|---|---|
| 普惠金融专营机制（普惠金融部 / 小微专营支行）+ 信贷工厂 | 评级、额度与审批规则的来源 |
| 个人手机银行已完成实名与签约能力 | 复用登录、三要素核验、协议签署与设备绑定 |
| 数据增信：银税互动、发票与收款流水、征信 | 近三个月经营流水与评级的取数来源 |
| 无还本续贷、年审制、随借随还 | 还款方式与宽限期设计的产品基础 |
| 尽职免责与不良容忍度、内部资金转移定价优惠 | 分行「敢贷愿贷」的机制保障（后台审核的依据） |
| 与政府性融资担保、风险补偿基金合作 | 「无抵押」的增信替代方案 |
| 经营账户与个人账户分账管理 + 反洗钱监测 | 账户隔离与取现限额控制的落地抓手 |

## 四、本样例的两个验证用途

1. **增量需求抽取验证**：与 `docs/samples/mb-手机银行开户签约需求.md` 对照使用，检验
   - 复用的既有要素（经营者三要素、手机号码、登录凭据）是否**命中同一知识页**，不重复建页；
   - 新增要素（经营签约身份、经营流水与评级、额度与授权、经营圈关系、宽限期、取现限额与分行审核）
     是否被正确建页，并带上**片段级溯源**（回到需求文档的具体片段）。
2. **经营圈关系与资金穿透验证**：经营圈成员（含**对公账户**）、授权范围、账户与经营者的关联，
   用于验证「多个账户是否指向同一经营者 / 实际使用人」这类穿透与反洗钱规则的判定。

## 五、验证过程（步骤与观察点）

| # | 步骤 | 命令 / 入口 | 预期观察点 |
|---|---|---|---|
| 1 | 需求入库 | 上传需求 md 到验证库（或沙箱库） | 文档与切片生成成功，切片可作为溯源锚点 |
| 2 | 结构抽取（模型 `ea`） | MCP `extract_and_save` | 抽到「经营用户签约 / 经营圈建立」等任务与步骤、关联实体（账户、经营者）；不出现企业类主体 |
| 3 | 概要设计 | 设计智能体（只到实体粒度） | 概要设计页有页面级溯源（指回需求页）；不出现属性名 |
| 4 | 服务详设（属性级） | 详设智能体 | 每个服务页有 `## 服务契约` / `## 属性操作` / `## 维护责任`（自维护 / 引用外部） |
| 5 | 函数依赖独立识别 | MCP `extract_and_save`（模型 `ea-service`） | 抽到如「经营者三要素 → 经营用户」「经营用户 → 可贷额度」等依赖，决定/被决定属性成对 |

`F4` 幂等键缺 FD 支撑、`F5` 不可溯源、`F6` 服务边界过宽。
