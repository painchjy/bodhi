> **M2 补充口径（2026-10-01 你的裁决）**：判断"要不要建 / 建成什么"的尺子**始终是"消费关系"**——这条知识将来**被哪个技能 / 哪个智能体引用或依赖**（作为需求溯源、测试验收、评测的源头）。**知识 ≠ 最终落地产物**，但两者之间**必须有 `consumes` / `derivesFrom` 的边**。这与"规则用知识的 triage"是**同一把尺**，由 `model_recommendation` 技能统一承载。
