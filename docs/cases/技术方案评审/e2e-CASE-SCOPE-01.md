# 生产问题分析：未签约交易被扣款

## 问题现象
部分未签约交易发生了扣款，问题在多个交易并发时出现。

## 根因假设
交易处理代码在异常分支写入了全局变量；该变量被多个交易共享，错误值会影响后续交易。

## 修复方案
将全局变量改为只在当前交易作用域内可见的局部变量，异常分支只修改当前交易状态。

## 业务前提
签约状态判断会读取该变量所在的处理结果；未签约交易不应进入扣款。修复后需要保证当前交易的作用域不向外部泄漏。

## 方案与目标的关系
全局变量的错误写入可能跨交易扩散；局部变量不跨作用域，能阻断这条传播路径。经排查，没有其他共享状态承载同一错误语义；未签约交易不应进入扣款。
