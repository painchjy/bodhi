## 设计开发铁律（CRITICAL）
- **mcp tools 和 skills无业务语义**：本系统基于本体模型开发，所有mcp tools和skills基于本体类、属性设计开发，本体类的实例属于业务领域的数据，**不允许**mcp tools和技能使用本体实例层的数据用于逻辑判断，只能使用类名、属性性名、comment定义的受控词表等本体模型中的数据。例如：要开发技术方案评审报告生成功能(mcp_tool or skill)，必须要有技术方案评审报告这个类，目前它是报告的子类，如果技术方案评审报告作为报告的实例，则只能开发报告生成功能。功能的输入由智能体根据场景上下文，使用技能、工具从领域知识库或工作知识库中获取（本体的实例层数据），所以功能的输入可以是基础数据类型以及本体的实例，从而实现业务/领域目的。
- **本体模型不引用实例内容**：本体模型的comment中可以定义受控词表，用于约束实例层的规范，但不应该引用实例的名称用于规则约束，严禁反向依赖。
