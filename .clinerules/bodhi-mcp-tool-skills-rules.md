## 设计开发铁律（CRITICAL）
__① 工具/技能只认"类型与属性"，不认"领域名词"__ 工具与技能只能引用 __本体中声明的类、属性、关系__ 及其取值域；不得出现任 __具体领域的名词、字段清单、判定口径、示例数据__。 业务口径一律落 __领域包__：本体实例页（流程/活动/任务/步骤/规则/数据对象/指标/模板）。 判定：`tests/biz_terms.txt` 词表扫描 `tools/**`、`skills/**` 命中 = __0__（`domains/**` 例外）。

__② 本体只描述"类—属性—关系—约束"，不出现实例__ 本体（`ontology/*.ttl`）不得引用任何实例名；实例只存在于知识库数据中。 判定：本体扫描实例名 = __0__；且 __只允许三处依赖领域信息__：`domains/**`（数据）、智能体配置/提示词、回归测试脚本。
